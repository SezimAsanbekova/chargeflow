# Тестирование логики зарядки

## Подготовка

### 1. Миграция базы данных

Убедитесь, что все модели в `prisma/schema.prisma` актуальны:

```bash
npm run db:generate
npm run db:push
```

### 2. Создание тестовых данных

Убедитесь, что у вас есть:
- Пользователь с балансом (минимум 200 сом для тестирования)
- Станция с доступными коннекторами
- Автомобиль, привязанный к пользователю

## Сценарии тестирования

### Сценарий 1: Успешная зарядка с достаточным балансом

**Начальные условия**:
- Баланс: 500 сом
- Цена станции: 14 сом/мин

**Шаги**:
1. Открыть `/map`
2. Выбрать станцию
3. Нажать "Начать зарядку"
4. Подтвердить начало зарядки
5. Проверить перенаправление на `/charging`
6. Проверить отображение:
   - Процент заряда увеличивается
   - Время зарядки растет
   - Баланс уменьшается каждую минуту на 14 сом
   - Списанная сумма увеличивается
7. Подождать 2-3 минуты
8. Нажать "Остановить зарядку"
9. Подтвердить остановку
10. Проверить страницу завершения:
    - Время зарядки корректное
    - Депозит: 100 сом
    - Поминутное списание: 14 * количество минут
    - Итого: 100 + поминутное списание
    - Баланс уменьшился на итоговую сумму
11. Нажать "Чек"
12. Проверить чек:
    - Все данные корректны
    - Можно скачать
13. Проверить историю зарядок (`/charging/history`)
    - Новая запись появилась
    - Можно открыть чек

**Ожидаемый результат**: Зарядка успешно завершена, средства списаны, чек создан

### Сценарий 2: Предупреждение о низком балансе

**Начальные условия**:
- Баланс: 130 сом (хватит на ~2 минуты при цене 14 сом/мин)
- Цена станции: 14 сом/мин

**Шаги**:
1. Начать зарядку (депозит 100 сом списан, остаток 30 сом)
2. Подождать 1 минуту (списано 14 сом, остаток 16 сом)
3. Проверить появление предупреждения "Мало средств, хватит на 1 минуту"
4. Нажать "Продолжить"
5. Подождать еще 1 минуту
6. Проверить автоматическую остановку зарядки
7. Проверить перенаправление на `/charging/stopped`
8. Проверить отображение:
   - Сообщение о недостатке средств
   - Баланс: 0 сом
   - Кнопка "Пополнить баланс"

**Ожидаемый результат**: Зарядка автоматически остановлена при нулевом балансе

### Сценарий 3: Недостаточный баланс для начала

**Начальные условия**:
- Баланс: 50 сом
- Цена станции: 14 сом/мин
- Минимум: 114 сом (100 депозит + 14 за минуту)

**Шаги**:
1. Открыть `/map`
2. Выбрать станцию
3. Нажать "Начать зарядку"
4. Проверить сообщение об ошибке
5. Проверить предложение пополнить баланс

**Ожидаемый результат**: Зарядка не начинается, предлагается пополнение

### Сценарий 4: Проверка активной сессии

**Начальные условия**:
- Есть активная сессия зарядки

**Шаги**:
1. Открыть `/map` в новой вкладке
2. Проверить автоматическое перенаправление на `/charging`
3. Попробовать начать новую зарядку через API
4. Проверить ошибку "У вас уже есть активная сессия"

**Ожидаемый результат**: Нельзя начать вторую зарядку, пока первая активна

### Сценарий 5: Поминутное списание

**Начальные условия**:
- Баланс: 500 сом
- Цена станции: 20 сом/мин

**Шаги**:
1. Начать зарядку
2. Записать начальный баланс после депозита
3. Подождать ровно 1 минуту
4. Проверить, что баланс уменьшился на 20 сом
5. Проверить, что создан новый Payment с type='charge'
6. Проверить, что costTotal увеличился на 20 сом
7. Проверить, что energyKwh увеличился
8. Подождать еще 1 минуту
9. Повторить проверки

**Ожидаемый результат**: Каждую минуту списывается точная цена станции

## Проверка базы данных

### Проверить ChargingSession

```sql
SELECT * FROM charging_sessions 
WHERE user_id = 'YOUR_USER_ID' 
ORDER BY start_time DESC 
LIMIT 1;
```

Проверить:
- `status` меняется с `active` на `completed`
- `end_time` устанавливается при остановке
- `cost_total` = депозит + поминутные списания
- `energy_kwh` увеличивается

### Проверить Payment

```sql
SELECT * FROM payments 
WHERE session_id = 'YOUR_SESSION_ID' 
ORDER BY created_at;
```

Проверить:
- Первый платеж: `type='deposit'`, `amount=100`
- Последующие платежи: `type='charge'`, `amount=pricePerMinute`
- Все платежи: `status='success'`

### Проверить Invoice

```sql
SELECT * FROM invoices 
WHERE session_id = 'YOUR_SESSION_ID';
```

Проверить:
- `amount` = `cost_total` из сессии
- `status='paid'`

### Проверить UserBalance

```sql
SELECT * FROM user_balance 
WHERE user_id = 'YOUR_USER_ID';
```

Проверить:
- Баланс уменьшился на итоговую сумму зарядки

## Тестирование API напрямую

### Начать зарядку

```bash
curl -X POST http://localhost:3000/api/charging/start \
  -H "Content-Type: application/json" \
  -d '{
    "connectorId": "CONNECTOR_ID",
    "vehicleId": "VEHICLE_ID"
  }'
```

### Получить активную сессию

```bash
curl http://localhost:3000/api/charging/active
```

### Поминутное списание (вызывается автоматически)

```bash
curl -X POST http://localhost:3000/api/charging/tick
```

### Остановить зарядку

```bash
curl -X POST http://localhost:3000/api/charging/stop \
  -H "Content-Type: application/json" \
  -d '{
    "sessionId": "SESSION_ID"
  }'
```

## Известные проблемы и решения

### Проблема: Зарядка не начинается

**Возможные причины**:
1. Нет доступных коннекторов → Проверить статус коннекторов в БД
2. Нет автомобилей у пользователя → Создать автомобиль
3. Недостаточный баланс → Пополнить баланс

### Проблема: Поминутное списание не работает

**Возможные причины**:
1. Интервал не запускается → Проверить консоль браузера
2. API возвращает ошибку → Проверить логи сервера
3. Сессия не активна → Проверить статус в БД

### Проблема: Баланс не обновляется

**Возможные причины**:
1. Транзакция не выполнилась → Проверить логи
2. UserBalance не существует → Создать запись
3. Decimal overflow → Проверить типы данных
