## Проверка работы

### Шаг 1: Запустите сервер
```bash
npm run dev
```

### Шаг 2: Проверьте тестовый API
Откройте в браузере:
```
http://localhost:3001/api/admin/test-stats
```

Должны увидеть JSON с данными:
```json
{
  "success": true,
  "data": {
    "users": { "total": 11 },
    "stations": { "total": 9 },
    "connectors": { "total": 18, "available": 5 }
  }
}
```

### Шаг 3: Откройте админ-панель
```
http://localhost:3001/admin/dashboard
```

### Шаг 4: Проверьте данные
- Карточки должны показывать реальные числа (не 0)
- График должен показывать зарядки за последние 30 дней
- Активность должна показывать последние события

## Если показывает 0

### Вариант 1: Проверьте тестовый API
Если тестовый API показывает данные, но админ-панель показывает 0:
- Проблема в авторизации
- Проверьте cookie `admin_token`
- Войдите заново

### Вариант 2: Проверьте БД
Если тестовый API тоже показывает 0:
- Данных действительно нет в БД
- Добавьте станции через админ-панель
- Или через Prisma Studio: `npm run prisma studio`

### Вариант 3: Проверьте логи
Откройте терминал где запущен `npm run dev`:
- Должны быть логи запросов
- Если есть ошибки - скопируйте их

### Вариант 4: Проверьте DevTools
1. Откройте DevTools (F12)
2. Network → обновите страницу
3. Найдите запрос `/api/admin/stats`
4. Проверьте статус и ответ

## Частые проблемы

### Проблема: Станции = 0
**Причина:** Нет записей в таблице `stations`

**Решение:**
```bash
# Откройте Prisma Studio
npm run prisma studio

# Проверьте таблицу stations
# Если пусто - добавьте станцию
```

### Проблема: График пустой
**Причина:** Нет зарядок за последние 30 дней

**Решение:**
- Создайте тестовую зарядку
- Или подождите реальных зарядок
- Сообщение "Нет зарядок за последние 30 дней" - это нормально

### Проблема: Unauthorized (401)
**Причина:** Нет cookie или истёк токен

**Решение:**
- Войдите заново как администратор
- Проверьте cookie в DevTools
