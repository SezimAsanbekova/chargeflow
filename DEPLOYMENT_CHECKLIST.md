# ✅ Чеклист деплоя на Timeweb App Platform

## Перед деплоем

### 1. Подготовка проекта
- [x] Dockerfile создан в корне проекта
- [x] .dockerignore настроен
- [x] next.config.ts содержит `output: 'standalone'`
- [ ] Код закоммичен и запушен в Git репозиторий
- [ ] .env файл НЕ включен в Git (проверьте .gitignore)

### 2. База данных
- [ ] PostgreSQL база данных создана в Timeweb Cloud
- [ ] Сохранена строка подключения DATABASE_URL
- [ ] База данных доступна (проверьте подключение)

### 3. Секретные ключи
Сгенерируйте секретные ключи командой:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

- [ ] NEXTAUTH_SECRET сгенерирован (минимум 32 символа)
- [ ] JWT_SECRET сгенерирован (минимум 32 символа)

### 4. Google OAuth (если используется)
- [ ] Google Cloud Console проект создан
- [ ] OAuth 2.0 Client ID создан
- [ ] Redirect URI добавлен: `https://ваш-домен.timeweb.cloud/api/auth/callback/google`
- [ ] GOOGLE_CLIENT_ID получен
- [ ] GOOGLE_CLIENT_SECRET получен

### 5. Email настройки (если используется)
- [ ] SMTP сервер настроен (Gmail, Mailgun, SendGrid и т.д.)
- [ ] App Password создан (для Gmail)
- [ ] EMAIL_USER и EMAIL_PASS готовы

## Деплой в Timeweb

### 6. Создание приложения
- [ ] Вход в панель Timeweb Cloud выполнен
- [ ] Раздел "App Platform" открыт
- [ ] Нажата кнопка "Создать приложение"
- [ ] Репозиторий подключен (GitHub/GitLab/Bitbucket)

### 7. Настройка приложения
- [ ] Тип приложения: **Backend (Node.js)**
- [ ] Ветка выбрана: **main** (или ваша основная)
- [ ] Dockerfile обнаружен автоматически
- [ ] Порт установлен: **3000**

### 8. Переменные окружения
Добавьте в Timeweb App Platform:

#### Обязательные:
- [ ] `DATABASE_URL` - строка подключения к PostgreSQL
- [ ] `NODE_ENV=production`
- [ ] `NEXTAUTH_URL` - https://ваш-домен.timeweb.cloud
- [ ] `NEXTAUTH_SECRET` - ваш сгенерированный секрет
- [ ] `JWT_SECRET` - ваш сгенерированный секрет
- [ ] `NEXT_PUBLIC_APP_URL` - https://ваш-домен.timeweb.cloud

#### Опциональные (если используются):
- [ ] `GOOGLE_CLIENT_ID`
- [ ] `GOOGLE_CLIENT_SECRET`
- [ ] `EMAIL_HOST`
- [ ] `EMAIL_PORT`
- [ ] `EMAIL_SECURE`
- [ ] `EMAIL_USER`
- [ ] `EMAIL_PASS`
- [ ] `EMAIL_FROM`

### 9. Запуск деплоя
- [ ] Кнопка "Создать приложение" нажата
- [ ] Процесс сборки запущен
- [ ] Логи сборки проверены (нет ошибок)
- [ ] Приложение успешно задеплоено

## После деплоя

### 10. Миграция базы данных
Выполните миграции Prisma одним из способов:

**Способ 1: Локально**
```bash
DATABASE_URL="ваш_database_url_из_timeweb" npx prisma migrate deploy
```

**Способ 2: Через консоль Timeweb**
```bash
npx prisma migrate deploy
```

- [ ] Миграции выполнены успешно
- [ ] Таблицы созданы в базе данных

### 11. Seed данных (опционально)
Если нужны начальные данные:
```bash
DATABASE_URL="ваш_database_url_из_timeweb" npm run db:seed
DATABASE_URL="ваш_database_url_из_timeweb" npm run db:seed:admin
```

- [ ] Seed данные загружены (если требуется)

- [ ] API эндпоинты работают

## 🔄 Обновления

При каждом `git push` в основную ветку:
- Автоматически запускается новый деплой
- Приложение пересобирается
- Новая версия разворачивается

**Важно:** Миграции БД нужно выполнять вручную при изменении схемы!
