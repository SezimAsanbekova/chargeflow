## Как использовать

### Просмотр статистики
Просто откройте страницу - все данные загрузятся автоматически из БД.

### Экспорт отчёта
1. Выберите период (сегодня/неделя/месяц)
2. Нажмите "Экспорт отчёта"
3. CSV файл скачается автоматически

### Обновление данных
Просто обновите страницу (F5) - данные загрузятся заново.

## Все данные из БД! 🎯

- **Пользователи**: `SELECT COUNT(*) FROM users WHERE role = 'user'`
- **Станции**: `SELECT COUNT(*) FROM stations`
- **Свободные**: `SELECT COUNT(*) FROM connectors WHERE status = 'available'`
- **Активные**: `SELECT COUNT(*) FROM charging_sessions WHERE status = 'active'`
- **Выручка**: `SELECT SUM(amount) FROM payments WHERE type = 'charge' AND created_at >= TODAY()`
- **Активность**: `SELECT * FROM (sessions + bookings + users) WHERE created_at >= NOW() - 24h LIMIT 10`
- **График**: `SELECT HOUR(created_at), COUNT(*) FROM charging_sessions WHERE created_at >= TODAY() GROUP BY HOUR`
