# Тестирование обновлённой админ-панели

## Как протестировать

### 1. Запустите проект
```bash
npm run dev
```

### 2. Откройте админ-панель
Перейдите по адресу: `http://localhost:3001/admin/dashboard`

### 3. Войдите как администратор
Используйте учётные данные администратора

## Что проверить

### ✅ Карточки с метриками
- [ ] **👥 Пользователей** - показывает реальное количество
- [ ] **🔌 Станций** - показывает общее количество + свободные коннекторы
- [ ] **⚡ Зарядка сейчас** - показывает активные сессии
- [ ] **💰 Выручка за день** - показывает доход за сегодня + количество зарядок

### ✅ График по времени суток
- [ ] Отображается 4 периода (Утро, День, Вечер, Ночь)
- [ ] Показывает количество зарядок для каждого периода
- [ ] Прогресс-бары с градиентом работают корректно

### ✅ Последняя активность
- [ ] Показывает последние 10 событий за 24 часа
- [ ] Отображаются иконки для разных типов событий (⚡📅👤)
- [ ] Показывается время события ("5 мин назад", "2 ч назад")
- [ ] Для зарядок показывается станция
- [ ] Для отменённых броней указывается потеря депозита

### ✅ Экспорт отчёта
- [ ] Выпадающий список с периодами работает
- [ ] Кнопка "Экспорт отчёта" активна
- [ ] При нажатии скачивается CSV файл
- [ ] CSV содержит данные за выбранный период
- [ ] Файл называется правильно (например: `report-today-2026-06-02.csv`)

### ✅ Статус системы
- [ ] Отображаются 3 статуса с зелёными галочками
- [ ] Все статусы показывают "работает"

### ✅ Адаптивность
- [ ] На мобильных устройствах карточки располагаются в 1 колонку
- [ ] На планшетах - в 2 колонки
- [ ] На десктопе - в 4 колонки

## Тестовые сценарии

### Сценарий 1: Проверка реальных данных
1. Создайте тестовую зарядку через приложение
2. Обновите страницу админ-панели
3. Убедитесь, что:
   - Счётчик "Зарядка сейчас" увеличился
   - В "Последней активности" появилось новое событие
   - График обновился

### Сценарий 2: Экспорт отчёта
1. Выберите период "За сегодня"
2. Нажмите "Экспорт отчёта"
3. Откройте скачанный CSV файл
4. Проверьте, что данные корректны

### Сценарий 3: Проверка активности
1. Зарегистрируйте нового пользователя
2. Создайте бронь
3. Начните зарядку
4. Обновите админ-панель
5. Убедитесь, что все 3 события отображаются в "Последней активности"

## Известные особенности

- Если за сегодня не было зарядок, выручка будет 0
- Если нет активности за 24 часа, показывается сообщение "Нет активности"
- График показывает только зарядки за текущий день (с 00:00 до 23:59)
- Время в активности показывается относительно текущего момента

## Что делать при ошибках

### Ошибка: "Unauthorized"
- Убедитесь, что вы вошли как администратор
- Проверьте, что cookie `admin_token` установлен

### Ошибка: "Internal server error"
- Проверьте подключение к базе данных
- Посмотрите логи в консоли сервера
- Убедитесь, что все миграции Prisma выполнены

### Данные не обновляются
- Обновите страницу (F5)
- Проверьте, что API `/api/admin/stats` возвращает данные
- Откройте DevTools → Network и проверьте запросы

## Производительность

Ожидаемое время загрузки:
- Первая загрузка: < 2 секунды
- Повторная загрузка: < 500 мс
- Экспорт отчёта: < 3 секунды (зависит от объёма данных)
