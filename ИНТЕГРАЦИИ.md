# 🔌 Все интеграции проекта ChargeFlow

## Список всех интеграций

### 1. 🤖 **OpenAI** (AI помощник)
**Что используется:**
- **GPT-4o / GPT-4o-mini** - AI чат для ответов пользователям
- **Whisper-1** - распознавание речи (Speech-to-Text)
- **TTS (Text-to-Speech)** - озвучивание ответов (голос "nova")

**Где используется:**
- `/api/ai-chat` - чат с AI помощником
- `/api/transcribe` - распознавание голоса
- `/api/text-to-speech` - озвучивание ответов
- `/ai-chat` - страница AI чата

**Настройка в .env:**
```env
OPENAI_API_KEY="sk-..."
NEXT_PUBLIC_OPENAI_API_KEY="sk-..."
```

**Документация:**
- `AI_CHAT_README.md`
- `AI_INTEGRATION_GUIDE.md`
- `AI_USER_GUIDE.md`
- `VOICE_CHAT_GUIDE.md`

---

### 2. 💳 **Finik** (Платежная система)
**Что используется:**
- Finik Acquiring API (Averspay)
- QR-код платежи (FINIK_QR)
- Webhook для подтверждения платежей
- Библиотека: `@mancho.devs/authorizer`

**Где используется:**
- `/api/finik/create-payment` - создание платежа
- `/api/finik/webhook` - получение подтверждений оплаты
- `/lib/finik.ts` - основная библиотека
- `/balance` - пополнение баланса

**Настройка в .env:**
```env
FINIK_ENV="beta"  # или "prod"
FINIK_API_KEY="your-api-key"
FINIK_ACCOUNT_ID="your-account-id"
FINIK_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----..."  # только для prod
```

**Документация:**
- `FINIK_INTEGRATION_GUIDE.md`

---

### 3. 🗺️ **MapLibre GL** (Карты)
**Что используется:**
- MapLibre GL JS (открытая альтернатива Mapbox)
- Интерактивные карты зарядных станций
- Навигация до станций

**Где используется:**
- `/map` - страница с картой станций
- `/map/components/` - компоненты навигации

**Настройка:**
```bash
npm install maplibre-gl
```

**Документация:**
- `app/map/DEVELOPER_NOTES.md`
- `app/map/API_EXAMPLES.md`

---

### 4. 🔐 **NextAuth.js** (Аутентификация)
**Что используется:**
- Сессии пользователей
- JWT токены
- Google OAuth (опционально)

**Где используется:**
- `/api/auth/[...nextauth]` - endpoints аутентификации
- `/lib/auth.ts` - конфигурация
- Все защищенные страницы

**Настройка в .env:**
```env
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your_secret_key"
JWT_SECRET="your_jwt_secret"
```

---

### 5. 🔑 **Google OAuth** (Вход через Google)
**Что используется:**
- Google Cloud Platform
- OAuth 2.0

**Настройка в .env:**
```env
GOOGLE_CLIENT_ID="your_client_id.apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET="your_client_secret"
```

---

### 6. 📧 **Email (SMTP)** (Уведомления)
**Что используется:**
- Nodemailer
- Gmail SMTP (или другой SMTP сервер)

**Где используется:**
- Отправка уведомлений пользователям
- Подтверждение регистрации
- Чеки об оплате

**Настройка в .env:**
```env
EMAIL_HOST="smtp.gmail.com"
EMAIL_PORT="587"
EMAIL_SECURE="false"
EMAIL_USER="your_email@gmail.com"
EMAIL_PASS="your_app_password"  # App Password от Gmail
EMAIL_FROM="ChargeFlow <your_email@gmail.com>"
```

---

### 7. 🗄️ **PostgreSQL + Prisma** (База данных)
**Что используется:**
- PostgreSQL - основная база данных
- Prisma ORM - работа с БД
- Prisma Adapter для PostgreSQL

**Настройка в .env:**
```env
DATABASE_URL="postgresql://username:password@localhost:5432/chargeflow?schema=public"
```

**Команды:**
```bash
npx prisma migrate dev    # миграции
npx prisma generate      # генерация клиента
npx prisma studio        # GUI для БД
```

## 📍 API Endpoints

### 🌐 Открытые (Public):
- `POST /api/auth/signin` - вход
- `POST /api/auth/signup` - регистрация
- `POST /api/auth/register` - регистрация с кодом
- `GET /api/stations` - **список всех станций с коннекторами**
- `GET /api/stations/[id]` - **детальная информация о станции**
- `GET /api/stations/[id]/available-slots` - доступные слоты для бронирования
- `GET /api/stations/[id]/active-session` - активная сессия на станции

### 🔒 Защищенные (Authenticated):
- `POST /api/ai-chat` - AI чат
- `POST /api/transcribe` - распознавание речи
- `POST /api/text-to-speech` - озвучивание
- `POST /api/finik/create-payment` - создание платежа
- `POST /api/finik/webhook` - webhook от Finik
- `GET /api/user/profile` - профиль пользователя
- `PUT /api/user/profile` - обновление профиля
- `GET /api/user/balance` - баланс пользователя
- `GET /api/user/bookings` - список бронирований
- `POST /api/user/bookings` - создание бронирования
- `GET /api/user/charging-history` - история зарядок
- `GET /api/user/transactions` - история транзакций
- `GET /api/vehicles` - список автомобилей пользователя
- `POST /api/vehicles` - добавление автомобиля
- `PUT /api/vehicles/[id]` - обновление автомобиля
- `DELETE /api/vehicles/[id]` - удаление автомобиля
- `POST /api/charging/start` - начало зарядки
- `POST /api/charging/stop` - остановка зарядки
- `GET /api/charging/active` - активная зарядка
- `GET /api/charging/history` - история зарядок
- `GET /api/charging/invoice/[id]` - получение чека

### 👑 Админские (Admin only):
- `GET /api/admin/stats` - общая статистика (пользователи, станции, сессии)
- `GET /api/admin/analytics` - аналитика (доход, энергия, коннекторы)
- `GET /api/admin/finance` - финансы (платежи, транзакции)
- `GET /api/admin/users` - **список всех пользователей**
- `GET /api/admin/users/[id]/history` - история пользователя
- `GET /api/admin/stations` - **список всех станций (админ)**
- `POST /api/admin/stations` - создание станции
- `GET /api/admin/stations/[id]` - детали станции
- `PUT /api/admin/stations/[id]` - обновление станции
- `DELETE /api/admin/stations/[id]` - удаление станции
- `GET /api/admin/bookings` - список бронирований
- `GET /api/admin/sessions` - список сессий зарядки

## � Основные листинги (Listings)

### 1. **Листинг станций** (`GET /api/stations`)
**Серверная часть:** `/app/api/stations/route.ts`

**Что возвращает:**
```typescript
[
  {
    id: string,
    name: string,
    address: string,
    latitude: number,
    longitude: number,
    status: 'available' | 'busy' | 'maintenance',
    maxPowerKw: number,
    pricePerMinute: number,
    connectorType: string,
    workingHours: object,
    connectors: [
      {
        id: string,
        type: 'CCS2' | 'CHAdeMO' | 'Type2' | 'GB_T',
        powerKw: number,
        pricePerKwh: number,
        pricePerMinute: number,
        status: 'available' | 'busy' | 'maintenance'
      }
    ]
  }
]
```

**Используется в:**
- `/map` - карта станций
- Главная страница
- AI чат (для рекомендаций)

---

### 2. **Листинг пользователей** (`GET /api/admin/users`)
**Серверная часть:** Связано с admin API

**Что возвращает:**
```typescript
{
  users: [
    {
      id: string,
      name: string,
      email: string,
      phone: string,
      balance: number,
      createdAt: string
    }
  ]
}
```

**Используется в:**
- `/admin/users` - страница пользователей
- `/admin/dashboard` - статистика

---

### 3. **Листинг автомобилей пользователя** (`GET /api/vehicles`)
**Серверная часть:** `/app/api/vehicles/route.ts`

**Что возвращает:**
```typescript
[
  {
    id: string,
    brand: string,
    model: string,
    year: number,
    connectorType: 'CCS2' | 'CHAdeMO' | 'Type2' | 'GB_T',
    maxPowerKw: number,
    batteryCapacityKwh: number
  }
]
```

**Используется в:**
- `/vehicles` - список автомобилей
- `/charging` - выбор авто для зарядки

---

### 4. **Листинг коннекторов станции**
**Включен в:** `GET /api/stations/[id]`

**Типы коннекторов:**
- `CCS2` - Combined Charging System (Европа)
- `CHAdeMO` - японский стандарт
- `Type2` - AC зарядка (Mennekes)
- `GB_T` - китайский стандарт

---

### 5. **Листинг истории зарядок** (`GET /api/charging/history`)
**Серверная часть:** `/app/api/charging/history/route.ts`

**Что возвращает:**
```typescript
{
  sessions: [
    {
      id: string,
      stationName: string,
      stationAddress: string,
      startTime: string,
      endTime: string,
      energyKwh: number,
      cost: number,
      status: 'completed' | 'active'
    }
  ]
}
```

---

### 6. **Листинг транзакций** (`GET /api/user/transactions`)
**Серверная часть:** `/app/api/user/transactions/route.ts`

**Что возвращает:**
```typescript
[
  {
    id: string,
    type: 'charge' | 'deposit' | 'refund' | 'topup',
    amount: number,
    status: 'success' | 'pending' | 'failed',
    createdAt: string
  }
]
```
