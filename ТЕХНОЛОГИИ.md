# 🛠️ Технологический стек ChargeFlow

## 📋 Краткий обзор

ChargeFlow построен на современном **Full-Stack JavaScript/TypeScript** стеке с использованием **Next.js 16** (App Router).

---

## 📊 База данных

### Схема (основные таблицы)

```prisma
model User {
  id            String
  email         String
  password      String
  name          String
  phone         String
  balance       Float
  vehicles      Vehicle[]
  bookings      Booking[]
  sessions      ChargingSession[]
  transactions  Transaction[]
}

model Station {
  id            String
  name          String
  address       String
  latitude      Float
  longitude     Float
  connectors    Connector[]
  bookings      Booking[]
}

model Connector {
  id            String
  type          String
  power         Float
  price         Float
  status        String
  station       Station
}

model Booking {
  id            String
  user          User
  station       Station
  connector     Connector
  startTime     DateTime
  endTime       DateTime
  status        String
}

model ChargingSession {
  id            String
  user          User
  booking       Booking
  startTime     DateTime
  endTime       DateTime
  energy        Float
  cost          Float
  status        String
}
```

## 🎯 Почему именно этот стек?

### ✅ Преимущества

1. **Full-Stack TypeScript**
   - Один язык для всего
   - Type safety везде
   - Легче поддерживать

2. **Next.js**
   - SEO friendly (SSR)
   - API Routes (не нужен отдельный backend)
   - Отличная производительность
   - Большое комьюнити

3. **Prisma**
   - Type-safe БД запросы
   - Простые миграции
   - Отличная документация

4. **PostgreSQL**
   - Надежная БД
   - ACID транзакции
   - Масштабируемая

5. **PWA**
   - Работает как приложение
   - Офлайн режим
   - Не нужен App Store
