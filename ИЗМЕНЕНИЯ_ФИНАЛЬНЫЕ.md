## Проверка станций

Если станции показывают 0, проверьте:

### 1. Через Prisma Studio
```bash
npm run prisma studio
```
Откройте таблицу `stations` и проверьте, есть ли записи.

### 2. Через админ-панель
Откройте: `http://localhost:3001/admin/stations`

Если станций нет, добавьте их через кнопку "Добавить станцию".

### 3. Через API
```bash
curl http://localhost:3001/api/admin/stats
```

Должен вернуть JSON с данными:
```json
{
  "totalUsers": 11,
  "totalStations": 9,
  "activeSessions": 1,
  "availableConnectors": 5,
  "recentActivity": [...],
  "hourlyData": [...]
}
```

## Запуск

```bash
# 1. Запустите dev сервер
npm run dev

# 2. Откройте админ-панель
http://localhost:3001/admin/dashboard

# 3. Войдите как администратор
```

## Если станции всё ещё показывают 0

### Вариант 1: Добавьте станции вручную
1. Откройте `http://localhost:3001/admin/stations`
2. Нажмите "Добавить станцию"
3. Заполните форму и сохраните

### Вариант 2: Проверьте БД
```bash
# Откройте Prisma Studio
npm run prisma studio

# Проверьте таблицу stations
# Если пусто - добавьте записи
```

### Вариант 3: Запустите seed
```bash
# Если есть seed скрипт
npm run prisma db seed
```
