# Логика активной зарядки

## Обзор

Система зарядки электромобилей с поминутным списанием средств с баланса пользователя.

**Важно**: Цена за минуту (`pricePerMinute`) берется из поля `pricePerKwh` коннектора. В текущей реализации это значение используется как цена за минуту зарядки.

## Основные компоненты

### 1. Депозит при бронировании/начале зарядки

- **Сумма депозита**: 100 сом
- **Списание**: При начале зарядки депозит списывается с баланса
- **Возврат**: Депозит НЕ возвращается отдельно, а входит в итоговую стоимость зарядки

### 2. Начало зарядки

**Минимальный баланс**: Депозит (100 сом) + цена 1 минуты зарядки

**Процесс**:
1. Проверка баланса пользователя
2. Списание депозита (100 сом)
3. Создание сессии зарядки (`ChargingSession`)
4. Создание платежа типа `deposit`
5. Обновление статуса коннектора на `charging`
6. Перенаправление на страницу активной зарядки

**API**: `POST /api/charging/start`

### 3. Активная зарядка

**Отображаемая информация**:
- Процент заряда батареи (симуляция)
- Текущая мощность (кВт)
- Время зарядки (минуты)
- Номер сессии
- Переданная энергия (кВт⋅ч)
- Время начала
- Цена за минуту для станции
- Текущий баланс
- Списанная сумма

**Обновление данных**:
- Каждые 5 секунд: обновление информации о сессии
- Каждую минуту: поминутное списание средств

**API**:
- `GET /api/charging/active` - получение данных активной сессии
- `POST /api/charging/tick` - поминутное списание

### 4. Поминутное списание

**Процесс каждую минуту**:
1. Проверка баланса пользователя
2. Если баланс >= цены минуты:
   - Списание средств с баланса
   - Создание платежа типа `charge`
   - Обновление `costTotal` и `energyKwh` в сессии
3. Если баланс < цены минуты:
   - Автоматическая остановка зарядки
   - Создание чека (`Invoice`)
   - Освобождение коннектора
   - Перенаправление на страницу остановки

**Расчет энергии**: `energyIncrement = maxPowerKw * 0.85 / 60` (кВт⋅ч за минуту)

### 5. Предупреждения о балансе

**Предупреждение "Мало средств"**:
- Показывается когда: `balance <= pricePerMinute * 2`
- Сообщение: "Осталось мало средств, хватит еще на 2 минуты"
- Кнопки: "Пополнить баланс" | "Продолжить"

**Предупреждение "Критически мало средств"**:
- Показывается когда: `balance <= pricePerMinute * 1`
- Сообщение: "Хватит на 1 минуту"
- Кнопки: "Пополнить баланс" | "Продолжить"

### 6. Остановка зарядки

#### Штатная остановка (пользователь нажал "Остановить")

**Процесс**:
1. Обновление сессии: установка `endTime`, статус `completed`
2. Освобождение коннектора: статус `available`
3. Создание чека (`Invoice`)
4. Перенаправление на страницу завершения

**Отображаемая информация**:
- Название станции
- Время зарядки
- Переданная энергия
- Депозит (100 сом)
- Поминутное списание
- Итоговая сумма
- Баланс после списания

**Кнопки**: "Чек" | "На главную"

**API**: `POST /api/charging/stop`

#### Автоматическая остановка (недостаток средств)

**Процесс**: Аналогичен штатной остановке

**Отображаемая информация**:
- Сообщение: "Зарядка остановлена из-за недостатка средств"
- Название станции
- Время зарядки
- Переданная энергия
- Списанная сумма (включая депозит)
- Баланс: 0 сом

**Кнопки**: "Пополнить баланс" | "На главную"

### 7. Чек (Receipt)

**Содержимое чека**:
- Номер чека (UUID)
- Дата и время сессии (начало - конец)
- Название станции
- Адрес станции
- Цена за минуту
- Время зарядки (минуты)
- Переданная энергия (кВт⋅ч)
- Депозит: 100 сом
- Поминутное списание: сумма
- **Итого**: депозит + поминутное списание
- Способ оплаты: Баланс

**Функции**:
- Скачать чек (PNG изображение)
- Закрыть

**API**: `GET /api/charging/invoice/[id]`

### 8. История зарядок

**Отображение**:
- Список всех завершенных зарядок
- Сортировка: от новых к старым
- Для каждой записи:
  - Название станции
  - Адрес
  - Дата и время
  - Время зарядки
  - Переданная энергия
  - Итоговая сумма

**Действия**:
- Нажатие на запись → открывается чек
- Если история пуста → сообщение "История пуста"

**API**: `GET /api/charging/history`

## Модели данных

### ChargingSession
```typescript
{
  id: string
  userId: string
  vehicleId: string
  connectorId: string
  bookingId?: string
  startTime: DateTime
  endTime?: DateTime
  energyKwh: Decimal
  costTotal: Decimal
  status: 'created' | 'active' | 'completed' | 'cancelled' | 'error'
  startedVia: 'qr' | 'app'
}
```

### Payment
```typescript
{
  id: string
  userId: string
  sessionId?: string
  amount: Decimal
  type: 'charge' | 'deposit' | 'refund' | 'topup'
  method: string
  status: 'pending' | 'success' | 'failed'
}
```

### Invoice
```typescript
{
  id: string
  userId: string
  sessionId: string
  amount: Decimal
  status: 'pending' | 'paid' | 'cancelled'
}
```

## API Endpoints

### Зарядка
- `POST /api/charging/start` - начать зарядку
- `POST /api/charging/stop` - остановить зарядку
- `GET /api/charging/active` - получить активную сессию
- `POST /api/charging/tick` - поминутное списание
- `GET /api/charging/session/[id]` - получить данные сессии
- `GET /api/charging/invoice/[id]` - получить чек
- `GET /api/charging/history` - получить историю зарядок

### Пользователь
- `GET /api/user/balance` - получить баланс
- `GET /api/user/vehicles` - получить автомобили
- `GET /api/user/transactions` - получить транзакции

### Станции
- `GET /api/stations/[id]` - получить данные станции с коннекторами

## Страницы

- `/charging` - активная зарядка
- `/charging/completed?sessionId=xxx` - завершение зарядки
- `/charging/stopped?sessionId=xxx&reason=insufficient_funds` - остановка из-за недостатка средств
- `/charging/receipt?invoiceId=xxx` - чек
- `/charging/history` - история зарядок

## Важные правила

1. **Депозит входит в итоговую стоимость** - не возвращается отдельно
2. **Все суммы округляются до целых сом** при отображении
3. **Цена за минуту берется из настроек станции** - может быть разной
4. **Автоматическая остановка** при балансе < цены 1 минуты
5. **Поминутное списание** происходит каждую минуту в фоне
6. **Real-time обновление** экрана каждые 5 секунд
