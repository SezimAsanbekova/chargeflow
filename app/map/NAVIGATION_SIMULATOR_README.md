# Имитация навигации (Тест-драйв)

## Описание

Реализована полноценная имитация навигации как в 2ГИС для тестирования маршрутов без реального GPS.

## Возможности

### 1. **Построение маршрута**
- Выберите станцию на карте
- Нажмите кнопку "Маршрут"
- Система построит маршрут по дорогам с пошаговыми инструкциями

### 2. **Тест-драйв (Имитация навигации)**
После построения маршрута доступны две кнопки:
- **"Начать тест-драйв"** - запускает имитацию движения
- **"Реальная навигация"** - использует реальный GPS

### 3. **Панель управления симуляцией**
При запуске тест-драйва появляется панель с:
- **Выбор скорости**: 10, 20, 40, 60 км/ч
- **Старт/Пауза**: управление движением
- **Сброс**: возврат к началу маршрута
- **Выход**: завершение тест-драйва

### 4. **Навигационная панель (как в 2ГИС)**

#### Верхняя часть:
- Оставшееся расстояние до станции
- Оставшееся время в пути
- Кнопка выхода

#### Основная панель:
- **Крупная стрелка направления** (поворот налево/направо/прямо)
- **Текст манёвра** ("Поверните налево", "Продолжайте прямо")
- **Расстояние до манёвра** (обновляется в реальном времени)
- **Предпросмотр следующего шага**

#### Список всех шагов:
- Кнопка "Показать все шаги" для просмотра полного маршрута
- Нумерация шагов с индикацией текущего
- Возможность перейти к любому шагу

### 5. **Автоматическое движение**
- Маркер пользователя плавно движется вдоль маршрута
- Карта автоматически следует за маркером
- Поворот маркера в направлении движения
- Автоматическое переключение на следующий шаг при достижении точки поворота

### 6. **Голосовые подсказки**
Система автоматически озвучивает:
- "Через 50 метров поверните налево"
- "Поверните направо"
- "Продолжайте движение прямо"
- И другие инструкции

### 7. **Обновление в реальном времени**
- Расстояние до следующего поворота обновляется каждую секунду
- Автоматическая смена инструкций при приближении к повороту
- Индикация пройденного времени

### 8. **Завершение поездки**
При достижении станции:
- Показывается сообщение "Вы прибыли"
- Отображается статистика: расстояние, время, сравнение с планом
- Маршрут автоматически очищается

## Технические детали

### Компоненты

1. **NavigationPanel.tsx**
   - Отображает навигационную панель в стиле 2ГИС
   - Показывает текущий и следующий манёвры
   - Управляет списком всех шагов

2. **NavigationSimulator.tsx**
   - Управляет имитацией движения по маршруту
   - Вычисляет позицию на основе скорости
   - Определяет текущий шаг и расстояние до него
   - Генерирует голосовые подсказки

3. **SimulationControls.tsx**
   - Панель управления симуляцией
   - Выбор скорости движения
   - Кнопки управления (старт/пауза/сброс/выход)

### Алгоритм работы

1. **Построение маршрута**
   - Использует OSRM API для получения маршрута
   - Извлекает координаты и пошаговые инструкции
   - Сохраняет данные для симуляции

2. **Симуляция движения**
   - Интерполяция позиции между точками маршрута
   - Вычисление направления (bearing) для поворота маркера
   - Обновление каждые 100ms для плавности

3. **Определение текущего шага**
   - Вычисление пройденного расстояния
   - Сравнение с накопленным расстоянием шагов
   - Автоматическое переключение при достижении

4. **Голосовые подсказки**
   - Использует Web Speech API
   - Озвучивает инструкции за 50 метров до поворота
   - Предотвращает повторное озвучивание одного шага

## Использование

### Базовый сценарий:

1. Откройте карту
2. Выберите станцию
3. Нажмите "Маршрут"
4. Нажмите "Начать тест-драйв"
5. Выберите скорость (по умолчанию 40 км/ч)
6. Нажмите "Старт"
7. Наблюдайте за движением и следуйте инструкциям

### Управление во время движения:

- **Пауза** - остановить движение
- **Продолжить** - возобновить движение
- **Сброс** - вернуться к началу маршрута
- **Изменить скорость** - выбрать другую скорость
- **Выход** - завершить тест-драйв

### Просмотр всех шагов:

1. Нажмите "Показать все шаги"
2. Просмотрите список манёвров
3. Нажмите на любой шаг для перехода к нему
4. Нажмите "Скрыть все шаги" для возврата

## Отличия от реальной навигации

- **Тест-драйв**: использует виртуальное движение, игнорирует реальный GPS
- **Реальная навигация**: использует реальный GPS устройства

## Визуальный стиль

Интерфейс выполнен в стиле 2ГИС:
- Тёмная панель внизу экрана
- Крупная стрелка направления
- Чёткие инструкции
- Информация о расстоянии и времени
- Предпросмотр следующего шага

## Поддерживаемые манёвры

- Начало движения
- Поворот налево/направо
- Поворот слегка налево/направо
- Резкий поворот налево/направо
- Продолжение прямо
- Круговое движение
- Развилка
- Конец дороги
- Прибытие к месту назначения

## Требования

- Современный браузер с поддержкой:
  - Geolocation API
  - Web Speech API (для голосовых подсказок)
  - MapLibre GL JS
- Интернет-соединение для загрузки карт и построения маршрутов

## Известные ограничения

- Голосовые подсказки могут не работать в некоторых браузерах
- Качество голоса зависит от браузера и ОС
- Симуляция не учитывает реальные пробки (только при построении маршрута)
