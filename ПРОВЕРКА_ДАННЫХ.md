# Проверка данных в админ-панели

## Проблема
Админ-панель показывает 0 для всех карточек, хотя данные в БД есть.

## Шаги для проверки

### 1. Запустите dev сервер
```bash
npm run dev
```

### 2. Проверьте тестовый API (без авторизации)
Откройте в браузере:
```
http://localhost:3001/api/admin/test-stats
```

Вы должны увидеть JSON с данными:
```json
{
  "success": true,
  "message": "Данные успешно получены",
  "data": {
    "users": {
      "total": 11,
      "list": [...]
    },
    "stations": {
      "total": 9,
      "list": [...]
    },
    "connectors": {
      "total": 18,
      "available": 5,
      ...
    }
  }
}
```

### 3. Если тестовый API показывает данные

Значит проблема в авторизации или в основном API. Проверьте:

#### A. Проверьте cookie
1. Откройте DevTools (F12)
2. Application → Cookies → http://localhost:3001
3. Найдите `admin_token`
4. Если нет - войдите заново

#### B. Проверьте основной API
Откройте DevTools → Network и обновите админ-панель.

Найдите запрос к `/api/admin/stats`:
- Статус должен быть 200
- Ответ должен содержать данные

### 4. Если тестовый API показывает 0

Значит данных действительно нет в БД. Добавьте их:

#### Через Prisma Studio
```bash
npm run prisma studio
```

1. Откройте таблицу `stations`
2. Добавьте станцию
3. Откройте таблицу `connectors`
4. Добавьте коннекторы к станции

#### Через админ-панель
```
http://localhost:3001/admin/stations
```
Нажмите "Добавить станцию"

### 5. Проверьте логи сервера

В терминале где запущен `npm run dev` должны быть логи:
```
🔍 Проверка данных БД...
✅ Данные получены: {...}
```

Если видите ошибки - скопируйте их.

## Частые проблемы

### Проблема 1: "Unauthorized" (401)
**Решение:** Войдите заново как администратор

### Проблема 2: "Forbidden" (403)
**Решение:** Убедитесь, что у пользователя роль `admin` в БД

### Проблема 3: Данные есть, но показывает 0
**Возможные причины:**
- Неправильный SQL запрос
- Проблема с типами данных
- Проблема с датами

**Проверка:**
```bash
# Откройте консоль PostgreSQL
psql -d your_database

# Проверьте пользователей
SELECT COUNT(*) FROM users WHERE role = 'user';

# Проверьте станции
SELECT COUNT(*) FROM stations;

# Проверьте коннекторы
SELECT COUNT(*) FROM connectors WHERE status = 'available';
```

### Проблема 4: График пустой
**Причина:** Нет зарядок за последние 30 дней

**Решение:** Создайте тестовую зарядку или измените период

## Отладка

### Включите подробные логи
В `app/api/admin/stats/route.ts` добавьте:
```typescript
console.log('Total users:', totalUsers);
console.log('Total stations:', totalStations);
console.log('Active sessions:', activeSessions);
console.log('Available connectors:', availableConnectors);
```

### Проверьте ответ API
```bash
# Через curl (замените на ваш токен)
curl -H "Cookie: admin_token=YOUR_TOKEN" \
  http://localhost:3001/api/admin/stats
```

## Контрольный список

- [ ] Dev сервер запущен
- [ ] Тестовый API показывает данные
- [ ] Cookie admin_token установлен
- [ ] Основной API возвращает 200
- [ ] В логах нет ошибок
- [ ] В БД есть данные (проверено через Prisma Studio)

## Если ничего не помогло

1. Скопируйте ошибку из консоли браузера
2. Скопируйте ошибку из терминала (логи сервера)
3. Скопируйте ответ от `/api/admin/test-stats`
4. Проверьте версию Node.js: `node -v` (должна быть >= 18)
5. Проверьте подключение к БД в `.env`
