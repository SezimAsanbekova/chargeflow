# 🔄 Перезапуск сервера разработки

## Проблема
Сервер не отвечает на `http://172.20.10.3:3000` - бесконечная загрузка.

## Причина
Конфликт `next-pwa` с Turbopack в режиме разработки.

## Решение
PWA конфигурация теперь применяется **только в production**.

## Как перезапустить

### 1. Остановите текущий сервер
В терминале где запущен `npm run dev`:
```bash
Ctrl + C
```

### 2. Запустите заново
```bash
npm run dev
```

### 3. Откройте в браузере
```
http://localhost:3000
# или
http://172.20.10.3:3000
```

## Проверка

Сервер должен запуститься без ошибок:
```
✓ Ready in 2.5s
○ Local:        http://localhost:3000
○ Network:      http://172.20.10.3:3000
```

## Если проблема сохраняется

### Очистите кэш
```bash
rm -rf .next
npm run dev
```

### Проверьте порт
```bash
lsof -ti:3000
# Если порт занят, убейте процесс:
kill -9 $(lsof -ti:3000)
```

### Проверьте браузер
1. Откройте DevTools (F12)
2. Вкладка Console - проверьте ошибки
3. Вкладка Network - проверьте запросы

## PWA в разработке

PWA функции **отключены** в режиме разработки:
- ❌ Service Worker не регистрируется
- ❌ Кэширование отключено
- ❌ Промпты установки не показываются

Это **нормально** и сделано специально для удобства разработки.

## PWA в production

Для тестирования PWA:
```bash
npm run build
npm start
```

Тогда все PWA функции будут работать:
- ✅ Service Worker
- ✅ Кэширование
- ✅ Офлайн режим
- ✅ Промпты установки
