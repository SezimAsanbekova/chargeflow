# 🌐 Исправление доступа по локальной сети

## Проблема
- ✅ `http://localhost:3000` - работает
- ❌ `http://172.20.10.3:3000` - бесконечная загрузка

## Причина
Next.js по умолчанию слушает только `localhost` (127.0.0.1), а не все сетевые интерфейсы.

## Решение
Изменил команду `dev` в `package.json`:
```json
"dev": "next dev -H 0.0.0.0"
```

Флаг `-H 0.0.0.0` заставляет Next.js слушать на всех сетевых интерфейсах.

## Как применить

### 1. Остановите сервер
В терминале где запущен `npm run dev`:
```bash
Ctrl + C
```

### 2. Запустите заново
```bash
npm run dev
```

### 3. Проверьте вывод
Должно быть:
```
✓ Ready in 2.5s
○ Local:        http://localhost:3000
○ Network:      http://172.20.10.3:3000
```

### 4. Откройте в браузере
Теперь оба адреса должны работать:
- ✅ `http://localhost:3000`
- ✅ `http://172.20.10.3:3000`

## Доступ с других устройств

Теперь вы можете открыть приложение:
- 📱 С телефона в той же WiFi сети
- 💻 С другого компьютера в той же сети
- 📱 Для тестирования PWA на реальном устройстве

Просто откройте `http://172.20.10.3:3000` на любом устройстве в вашей локальной сети.

## Безопасность

⚠️ **Важно:** Сервер разработки теперь доступен всем в вашей локальной сети.

Это безопасно для:
- ✅ Домашней WiFi сети
- ✅ Офисной сети
- ✅ Тестирования на мобильных устройствах

Не используйте в:
- ❌ Публичных WiFi сетях
- ❌ Production окружении

## Альтернативные способы

### Способ 1: Через переменную окружения
```bash
HOST=0.0.0.0 npm run dev
```

### Способ 2: Через конфигурацию
Создайте `.env.local`:
```
HOST=0.0.0.0
```

### Способ 3: Напрямую
```bash
next dev -H 0.0.0.0 -p 3000
```

   - iOS: Safari → Поделиться → На экран «Домой»

3. **Протестировать офлайн:**
   - Установите приложение

   - Проверьте работу

## Проверка IP адреса

Если IP изменился, проверьте:

### macOS:
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

### Или проще:
```bash
ipconfig getifaddr en0
```

## Если всё равно не работает

### 1. Проверьте firewall
```bash
# Временно отключите firewall для теста
# Системные настройки → Безопасность → Firewall
```

### 2. Проверьте порт
```bash
lsof -i :3000
```

### 3. Проверьте сеть
Убедитесь что оба устройства в одной сети:
```bash
ping 172.20.10.3
```

### 4. Попробуйте другой порт
```bash
npm run dev -- -p 3001
```

## Production

Для production используйте:
```bash
npm run build
npm start -- -H 0.0.0.0
```

Или настройте через переменные окружения в вашем хостинге.
