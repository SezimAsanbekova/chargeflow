## 🚀 Как использовать

### Для пользователей

**Android/Desktop:**
1. Откройте сайт в Chrome/Edge
2. Нажмите "Установить" в баннере
3. Готово!

**iOS:**
1. Откройте сайт в Safari
2. Нажмите "Поделиться" → "На экран «Домой»"
3. Готово!

### Для разработчиков

```bash
# Установка зависимостей
npm install

# Генерация иконок (если изменили логотип)
npm run pwa:icons

# Разработка (PWA отключено)
npm run dev

# Сборка с PWA
npm run build

# Запуск production
npm start
```

## 🐛 Отладка

### Проблемы с установкой
```bash
# Очистить кэш и пересобрать
rm -rf .next
npm run build
```

### Проблемы с Service Worker
```javascript
// В консоли браузера
navigator.serviceWorker.getRegistrations()
  .then(r => r.forEach(reg => reg.unregister()));
```

### Проблемы с иконками
```bash
# Перегенерировать иконки
npm run pwa:icons
npm run build
```
