# 📊 Руководство по админ-панели ChargeFlow

## Обзор

Админ-панель ChargeFlow - это мощная система управления платформой зарядных станций для электромобилей. Панель предоставляет полный контроль над пользователями, станциями, бронированиями, финансами и настройками системы.

## 🔐 Вход в систему

### Адрес входа
```
/admin/signin
```

### Процесс входа
1. **Введите email администратора** - ваш email, зарегистрированный как администратор
2. **Введите пароль** - ваш пароль администратора
3. **Получите код в Telegram** - система отправит 6-значный код в ваш Telegram
4. **Введите код** - введите полученный код на странице `/admin/verify-code`
5. **Готово!** - вы вошли в админ-панель

### Безопасность
- ✅ Двухфакторная аутентификация через Telegram
- ✅ Коды действительны ограниченное время
- ✅ Защита от брутфорса
- ✅ Автоматический выход при неактивности

   - Обновляется в реальном времени

- Отображается в сомах
- Большая карточка с градиентом

## 📊 Аналитика

**Путь:** `/admin/analytics`

### Функции

#### Фильтры по периодам
- **Все время** - статистика за весь период работы
- **День** - за сегодня
- **Неделя** - за последние 7 дней
- **Месяц** - за последние 30 дней
- **Год** - за последние 12 месяцев
- **Кастом** - выбор конкретной даты

#### Основная статистика

1. **Всего сессий**
   - Количество сессий зарядки за выбранный период
   - Иконка: ⚡ Zap

2. **Энергия**
   - Общее количество потребленной энергии
   - Единица: кВт⋅ч (киловатт-часы)
   - Иконка: 📈 TrendingUp

3. **Доход**
   - Общий доход за период
   - Единица: сом
   - Иконка: 💵 DollarSign

4. **Пользователей**
   - Количество активных пользователей за период
   - Иконка: 👥 Users

#### Дополнительная статистика

- **Среднее время сессии** - в минутах
- **Средний доход за сессию** - в сомах
- **Всего пользователей в системе** - общее количество
- **Всего станций** - общее количество

#### Экспорт отчетов

**Кнопка:** "Скачать отчет (PDF)"

Создает PDF-отчет с:
- Основной статистикой
- Дополнительной статистикой
- Информацией о системе
- Датой создания отчета

**Формат:** Готов к печати

## 👥 Пользователи

**Путь:** `/admin/users`

### Функции

#### Поиск
- Поиск по **телефону**
- Поиск по **email**
- Поиск по **имени**
- Поиск в реальном времени

#### Фильтры
1. **Все** - все пользователи
2. **Активные** - не заблокированные пользователи
3. **Заблокированные** - заблокированные пользователи

#### Информация о пользователе

Каждая карточка показывает:
- **Аватар** - инициалы пользователя
- **Имя** - имя пользователя или телефон/email
- **Статус** - активен или заблокирован
- **Телефон** - номер телефона
- **Email** - электронная почта
- **Количество сессий** - сколько раз заряжался

#### Действия

1. **Заблокировать** (🚫 Ban)
   - Блокирует пользователя
   - Пользователь не сможет войти в систему
   - Кнопка красная

2. **Разблокировать** (✅ CheckCircle)
   - Разблокирует пользователя
   - Пользователь снова может войти
   - Кнопка зеленая

3. **История** (📜 History)
   - Переход к истории сессий пользователя
   - Путь: `/admin/users/[id]/history`
   - Кнопка серая

#### Статистика внизу

- **Всего пользователей** - общее количество
- **Активных** - не заблокированные (зеленый)
- **Заблокированных** - заблокированные (красный)

## 📍 Станции

**Путь:** `/admin/stations`

### Функции

#### Кнопки управления
- **Назад** - возврат к дашборду
- **Добавить станцию** - создание новой станции

#### Фильтры

**Панель фильтров:**

1. **Поиск по названию/адресу**
   - Поиск в реальном времени
   - Ищет в названии и адресе

2. **Статус**
   - Все статусы
   - Активна
   - Обслуживание
   - Отключена

3. **Дата создания с** - начальная дата
4. **Дата создания до** - конечная дата

**Кнопка "Очистить"** - сбрасывает все фильтры

#### Карточка станции

Каждая карточка показывает:

**Верх:**
- **Статус** - цветной бейдж (зеленый/желтый/красный)
- **Кнопки действий:**
  - ✏️ **Редактировать** - изменить станцию
  - 🗑️ **Удалить** - удалить станцию (с подтверждением)

**Информация:**
- **Название** - название станции
- **Адрес** - полный адрес с иконкой 📍
- **Количество разъёмов** - сколько разъёмов доступно
- **Типы разъёмов** - Type 2, CCS, CHAdeMO и т.д.

#### Добавление станции

**Путь:** `/admin/stations/new`

**Поля:**
- Название станции
- Адрес
- Координаты (широта, долгота)
- Статус (активна/обслуживание/отключена)
- Разъёмы:
  - Тип (Type 2, CCS, CHAdeMO)
  - Мощность (кВт)
  - Цена за кВт⋅ч
  - Статус

#### Редактирование станции

**Путь:** `/admin/stations/[id]/edit`

Те же поля, что и при создании, но с предзаполненными данными.

## ⚙️ Настройки

**Путь:** `/admin/settings`

### Разделы настроек

#### 1. Telegram

**Иконка:** 💬 MessageSquare (синий)

**Параметры:**
- **Bot Token**
  - Токен бота для отправки уведомлений
  - Формат: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`
  - Используется для отправки кодов входа

- **Admin Telegram User ID**
  - Telegram ID администратора
  - Формат: `123456789`
  - Куда отправлять коды входа

#### 2. Email

**Иконка:** 📧 Mail (фиолетовый)

**Параметры:**
- **SMTP Host** - адрес SMTP сервера (например, `smtp.gmail.com`)
- **SMTP Port** - порт SMTP (обычно `587`)
- **SMTP Secure** - использовать TLS (true/false)
- **SMTP User** - email для отправки
- **SMTP Password** - пароль от email
- **From Email** - email отправителя (например, `noreply@chargeflow.com`)

#### 3. Платежи

**Иконка:** 💵 DollarSign (зеленый)

**Параметры:**
- **Минимальная сумма пополнения** - в сомах (например, 100)
- **Сумма депозита за бронирование** - в сомах (например, 50)
- **Комиссия системы** - в процентах (например, 5%)

#### 4. Система

**Иконка:** ⚙️ Settings (желтый)

**Параметры:**
- **Название приложения** - ChargeFlow
- **URL приложения** - https://chargeflow.com
- **Поддержка Email** - support@chargeflow.com
- **Поддержка Телефон** - +996 XXX XXX XXX

### Сохранение настроек

**Кнопки:**
- **Назад к панели** - возврат без сохранения
- **Сохранить настройки** - сохранить все изменения

**Уведомления:**
- ✅ Зеленое - "Настройки успешно сохранены"
- ❌ Красное - "Ошибка сохранения настроек"

## 🛠️ Техническая информация

### Технологии

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Authentication:** Custom JWT + Telegram
- **Database:** PostgreSQL (via Prisma)

### API Endpoints

**Админские API:**
- `/api/admin/me` - информация о текущем админе
- `/api/admin/stats` - статистика дашборда
- `/api/admin/users` - список пользователей
- `/api/admin/users/[id]/block` - блокировка пользователя
- `/api/admin/stations` - список станций
- `/api/admin/stations/[id]` - CRUD станции
- `/api/admin/bookings` - список бронирований
- `/api/admin/finance` - финансовая статистика
- `/api/admin/analytics` - аналитика
- `/api/admin/settings` - настройки системы
- `/api/admin/send-code` - отправка кода входа
- `/api/admin/verify-code` - проверка кода
- `/api/admin/logout` - выход
