# Руководство по деплою на Timeweb App Platform

## 📋 Подготовка к деплою

### 1. Подготовка базы данных
Перед деплоем приложения создайте PostgreSQL базу данных в Timeweb Cloud:
- Перейдите в раздел "Базы данных"
- Создайте новую PostgreSQL базу данных
- Сохраните строку подключения (DATABASE_URL)

### 2. Настройка переменных окружения в Timeweb

В панели управления App Platform добавьте следующие переменные окружения:

#### Обязательные переменные:

```bash
# База данных (получите из созданной БД в Timeweb)
DATABASE_URL=postgresql://username:password@host:port/database?schema=public

# Окружение
NODE_ENV=production

# NextAuth (замените на свои значения)
NEXTAUTH_URL=https://ваш-домен.timeweb.cloud
NEXTAUTH_SECRET=ваш_секретный_ключ_минимум_32_символа

# JWT для админ-панели (замените на свой секретный ключ)
JWT_SECRET=ваш_jwt_секретный_ключ_минимум_32_символа

# Google OAuth (если используете)
GOOGLE_CLIENT_ID=ваш_google_client_id
GOOGLE_CLIENT_SECRET=ваш_google_client_secret

# Email конфигурация
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_SECURE=false
EMAIL_USER=ваш_email@gmail.com
EMAIL_PASS=ваш_app_password
EMAIL_FROM=ChargeFlow <ваш_email@gmail.com>

# URL приложения
NEXT_PUBLIC_APP_URL=https://ваш-домен.timeweb.cloud
```

### 3. Генерация секретных ключей

Для генерации безопасных секретных ключей используйте:

```bash
# Для NEXTAUTH_SECRET и JWT_SECRET
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

## 🚀 Процесс деплоя

### Шаг 1: Подключение репозитория
1. Войдите в панель управления Timeweb Cloud
2. Перейдите в раздел "App Platform"
3. Нажмите "Создать приложение"
4. Подключите ваш GitHub/GitLab/Bitbucket репозиторий

### Шаг 2: Настройка приложения
1. **Тип приложения**: Backend (Node.js)
2. **Ветка**: main (или ваша основная ветка)
3. **Dockerfile**: Timeweb автоматически обнаружит Dockerfile в корне проекта
4. **Порт**: 3000

### Шаг 3: Добавление переменных окружения
1. В настройках приложения найдите раздел "Переменные окружения"
2. Добавьте все переменные из списка выше
3. Сохраните изменения

### Шаг 4: Миграция базы данных
После первого деплоя необходимо выполнить миграции Prisma:

1. Подключитесь к контейнеру через консоль Timeweb или используйте локальную машину
2. Выполните команду:
```bash
npx prisma migrate deploy
```

Или локально с DATABASE_URL из Timeweb:
```bash
DATABASE_URL="ваш_database_url_из_timeweb" npx prisma migrate deploy
```

### Шаг 5: Запуск деплоя
1. Нажмите "Создать приложение"
2. Дождитесь завершения сборки и деплоя
3. Приложение будет доступно по техническому домену Timeweb

## 🔄 Автоматический деплой

При включенном автодеплое (по умолчанию включен):
- Каждый `git push` в выбранную ветку автоматически запускает новый деплой
- Процесс включает: подтягивание кода → установка зависимостей → сборка → запуск

## 🔧 Важные особенности

### Хранение данных
- **Файлы**: Используйте S3-совместимое хранилище (например, Timeweb S3) для загружаемых файлов
- **База данных**: Используйте внешнюю PostgreSQL БД (не внутри контейнера)
- **Сессии**: Храните в базе данных, не в памяти приложения

### Логи
- Логи доступны в панели управления Timeweb
- Используйте `console.log()` для отладки

### Масштабирование
- App Platform автоматически управляет ресурсами
- При необходимости можно увеличить ресурсы в настройках

## 🐛 Решение проблем

### Ошибка при сборке
1. Проверьте логи сборки в панели Timeweb
2. Убедитесь, что все зависимости указаны в `package.json`
3. Проверьте, что Dockerfile корректен

### Ошибка подключения к БД
1. Проверьте правильность DATABASE_URL
2. Убедитесь, что БД доступна из App Platform
3. Проверьте, что выполнены миграции Prisma

### Приложение не запускается
1. Проверьте логи контейнера
2. Убедитесь, что все обязательные переменные окружения установлены
3. Проверьте, что порт 3000 открыт
