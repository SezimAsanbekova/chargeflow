## Проверка интерфейса

### Карточки (4 штуки)
- [ ] **👥 Пользователей** - отображается число
- [ ] **🔌 Станций** - отображается число + свободные
- [ ] **⚡ Зарядка сейчас** - отображается число активных сессий
- [ ] **💰 Выручка за день** - отображается сумма + количество зарядок

### Проверка данных
- [ ] Все числа реальные (не 0, если есть данные в БД)
- [ ] Иконки отображаются корректно
- [ ] Цвета карточек разные (зелёный, синий, фиолетовый, жёлтый)
- [ ] Текст читаемый на тёмном фоне

### График по времени суток
- [ ] Отображается 4 периода (Утро, День, Вечер, Ночь)
- [ ] Для каждого периода показано количество зарядок
- [ ] Прогресс-бары работают (длина зависит от количества)
- [ ] Градиент на прогресс-барах виден
- [ ] Если зарядок нет, показывается "0 зарядок"

### Последняя активность
- [ ] Отображается список событий (до 10 штук)
- [ ] Каждое событие имеет иконку (⚡📅👤)
- [ ] Показывается имя пользователя
- [ ] Показывается название станции (где применимо)
- [ ] Время отображается относительно ("5 мин назад", "2 ч назад")
- [ ] Если нет активности, показывается сообщение

### Экспорт отчёта
- [ ] Выпадающий список с 3 опциями (сегодня, неделя, месяц)
- [ ] Кнопка "Экспорт отчёта" активна
- [ ] При клике скачивается CSV файл
- [ ] Имя файла содержит период и дату
- [ ] CSV открывается в Excel/Google Sheets
- [ ] Данные в CSV корректные

### Статус системы
- [ ] Отображается 3 статуса
- [ ] Все статусы зелёные (🟢)
- [ ] Текст читаемый

### Тестовые сценарии

#### Сценарий 1: Создание зарядки
1. [ ] Откройте приложение как пользователь
2. [ ] Начните зарядку на любой станции
3. [ ] Вернитесь в админ-панель
4. [ ] Обновите страницу (F5)
5. [ ] Проверьте:
   - [ ] "Зарядка сейчас" увеличилась на 1
   - [ ] В активности появилось событие "начал зарядку"
   - [ ] График обновился (если зарядка в текущем часе)

1. [ ] Зарегистрируйте нового пользователя
2. [ ] Вернитесь в админ-панель
3. [ ] Обновите страницу
4. [ ] Проверьте:
   - [ ] "Пользователей" увеличилось на 1
   - [ ] В активности появилось "Зарегистрировался новый пользователь"

#### Сценарий 3: Экспорт отчёта
1. [ ] Выберите "За сегодня"
2. [ ] Нажмите "Экспорт отчёта"
3. [ ] Откройте скачанный файл
4. [ ] Проверьте:
   - [ ] Есть заголовки столбцов
   - [ ] Есть данные (если были зарядки/платежи)
   - [ ] Даты корректные
   - [ ] Суммы правильные

## Проверка адаптивности

### Десктоп (> 1024px)
- [ ] Карточки в 4 колонки
- [ ] Всё помещается на экран
- [ ] Нет горизонтальной прокрутки

### Планшет (768px - 1024px)
- [ ] Карточки в 2 колонки
- [ ] График читаемый
- [ ] Кнопка экспорта не перекрывает заголовок

### Мобильный (< 768px)
- [ ] Карточки в 1 колонку
- [ ] Кнопка экспорта под заголовком
- [ ] Всё читаемо без зума
