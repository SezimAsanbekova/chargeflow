# AI Chat с GPT-4o-mini и Whisper

## Что реализовано:

### Модели:
- **GPT-4o-mini** - для текстовых ответов (быстрая и доступная)
- **Whisper-1** - для распознавания речи
- **TTS-1 (nova)** - для озвучивания ответов AI

### Функции:
✅ Текстовый чат
✅ Запись голосовых сообщений
✅ Автоматическая транскрипция аудио
✅ **Голосовые ответы AI** (автоматически озвучиваются)
✅ Кнопка повторного прослушивания для каждого ответа
✅ Ответы на русском/кыргызском/английском
✅ Дизайн в стиле WhatsApp
✅ История сообщений с временными метками

## Как использовать:

1. **Получите правильный API ключ:**
   - Зайдите на https://platform.openai.com/api-keys
   - Создайте новый ключ
   - Убедитесь, что у вас есть кредиты на балансе

2. **Обновите `.env`:**
   ```env
   OPENAI_API_KEY="ваш-новый-ключ"
   ```

3. **Перезапустите сервер:**
   ```bash
   npm run dev
   ```

4. **Откройте чат:**
   - Нажмите на центральную кнопку AI (✨) в нижней панели
   - Или перейдите на `/ai-chat`

## Endpoints:

- `POST /api/ai-chat` - отправка текстовых сообщений
- `POST /api/transcribe` - транскрипция аудио (Speech-to-Text)
- `POST /api/text-to-speech` - озвучивание текста (Text-to-Speech)

## Как работает голосовой чат:

1. **Вы говорите** → Whisper распознаёт речь → Текст отправляется в GPT
2. **GPT отвечает** → Текст автоматически озвучивается через TTS → Вы слышите ответ
3. **Можно переслушать** → Кнопка "Прослушать" под каждым ответом AI

### Голоса TTS:
Текущий голос: **nova** (женский, естественный)

Доступные голоса:
- `alloy` - нейтральный
- `echo` - мужской
- `fable` - британский акцент
- `onyx` - глубокий мужской
- `nova` - женский (используется)
- `shimmer` - мягкий женский

Чтобы изменить голос, отредактируйте `app/api/text-to-speech/route.ts`, строку `voice: "nova"`

## О Realtime API:

**gpt-4o-realtime-preview** - это специальная модель для real-time голосового общения через WebSocket. Она:
- Работает только через WebSocket API (не REST)
- Позволяет вести диалог в реальном времени
- Более сложная в реализации

Текущая реализация использует **REST API** с:
- GPT-4o-mini для текста
- Whisper для аудио

Это проще, дешевле и работает стабильно.

Если нужен именно Realtime API - это отдельная большая задача с WebSocket соединением.
