# 📱 ChargeFlow PWA - Руководство

## Что такое PWA?

ChargeFlow теперь является Progressive Web App (PWA) - это означает, что приложение можно установить на ваше устройство и использовать как нативное приложение с дополнительными возможностями:

- ✅ **Установка на устройство** - работает как обычное приложение
- ✅ **Работа офлайн** - доступ к основным функциям без интернета
- ✅ **Быстрая загрузка** - кэширование ресурсов
- ✅ **Push-уведомления** - получайте уведомления о зарядке
- ✅ **Автоматические обновления** - всегда актуальная версия
- ✅ **Экономия трафика** - меньше загрузок данных

## 🚀 Установка PWA

### На Android (Chrome/Edge)

1. Откройте ChargeFlow в браузере Chrome или Edge
2. Нажмите на кнопку "Установить" в появившемся баннере
3. Или откройте меню браузера (⋮) → "Установить приложение"
4. Подтвердите установку
5. Приложение появится на главном экране

### На iOS (Safari)

1. Откройте ChargeFlow в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Прокрутите вниз и выберите "На экран «Домой»"
4. Нажмите "Добавить"
5. Приложение появится на главном экране

### На Desktop (Chrome/Edge)

1. Откройте ChargeFlow в браузере
2. Нажмите на иконку установки в адресной строке
3. Или откройте меню → "Установить ChargeFlow"
4. Приложение откроется в отдельном окне

## 🎯 Основные возможности PWA

### 1. Работа офлайн

Приложение кэширует следующие данные:
- Карта зарядных станций (последние загруженные)
- История зарядок
- Профиль пользователя
- Статические ресурсы (иконки, стили)

**Что работает офлайн:**
- Просмотр карты (последняя загруженная область)
- Просмотр истории зарядок
- Просмотр профиля
- Навигация по приложению

**Что требует интернета:**
- Построение новых маршрутов
- Начало зарядки
- Пополнение баланса
- Обновление данных станций

### 2. Индикатор подключения

В верхней части экрана появляется уведомление:
- 🔴 **Красное** - нет подключения к интернету
- 🟢 **Зеленое** - соединение восстановлено

### 3. Промпт установки

При первом посещении появляется баннер с предложением установить приложение:
- **Установить** - установить приложение
- **Позже** - скрыть баннер (можно установить позже через меню браузера)

Баннер не появится снова, если вы нажали "Позже". Для установки используйте меню браузера.

### 4. Автоматические обновления

Приложение автоматически проверяет обновления каждые 60 секунд:
- При обнаружении новой версии появится уведомление
- Нажмите "Обновить" для применения изменений
- Или обновите страницу вручную

### 5. Ярлыки приложения

После установки доступны быстрые действия (долгое нажатие на иконку):
- 🗺️ **Карта станций** - открыть карту
- 👤 **Мой профиль** - открыть профиль
- 📜 **История зарядок** - посмотреть историю

## 🔧 Технические детали

### Кэширование

Приложение использует следующие стратегии кэширования:

1. **CacheFirst** (приоритет кэша):
   - Шрифты Google Fonts
   - Аудио файлы (голосовая навигация)
   - Видео файлы

2. **StaleWhileRevalidate** (показать кэш, обновить в фоне):
   - Изображения
   - CSS стили
   - JavaScript файлы
   - Next.js данные

3. **NetworkFirst** (приоритет сети):
   - API запросы
   - Динамические данные

### Service Worker

Service Worker автоматически регистрируется в production режиме:
- Файл: `/public/sw.js`
- Обновляется автоматически
- Управляет кэшированием и офлайн режимом

### Manifest

Файл манифеста: `/public/manifest.json`

Содержит:
- Название и описание приложения
- Иконки всех размеров
- Цветовую схему
- Настройки отображения
- Ярлыки приложения

## 🛠️ Разработка

### Генерация иконок

```bash
node scripts/generate-icons.js
```

Скрипт создаст все необходимые иконки из `public/logo12.png`.

### Сборка

```bash
npm run build
```

При сборке автоматически генерируется Service Worker с настройками кэширования.

### Тестирование PWA

1. **Lighthouse** (Chrome DevTools):
   - Откройте DevTools (F12)
   - Вкладка "Lighthouse"
   - Выберите "Progressive Web App"
   - Нажмите "Generate report"

2. **Application** (Chrome DevTools):
   - Вкладка "Application"
   - Проверьте Manifest
   - Проверьте Service Workers
   - Проверьте Cache Storage

3. **Офлайн режим**:
   - DevTools → Network → Offline
   - Проверьте работу приложения

## 🎨 Кастомизация

### Изменение цветовой схемы

Отредактируйте `public/manifest.json`:

```json
{
  "theme_color": "#10b981",
  "background_color": "#ffffff"
}
```

### Изменение иконок

1. Замените `public/logo12.png` на свой логотип
2. Запустите `node scripts/generate-icons.js`
3. Пересоберите приложение

### Настройка кэширования

Отредактируйте `next.config.ts`:

```typescript
runtimeCaching: [
  {
    urlPattern: /\/api\/.*/,
    handler: 'NetworkFirst',
    options: {
      cacheName: 'api-cache',
      expiration: {
        maxEntries: 50,
        maxAgeSeconds: 60 * 60 // 1 час
      }
    }
  }
]
```

## 🐛 Отладка

### Проблемы с установкой

1. Проверьте, что приложение работает по HTTPS
2. Проверьте наличие `manifest.json`
3. Проверьте регистрацию Service Worker в DevTools
4. Очистите кэш браузера

### Проблемы с обновлением

1. Откройте DevTools → Application → Service Workers
2. Нажмите "Unregister"
3. Обновите страницу
4. Service Worker зарегистрируется заново

### Проблемы с кэшем

1. DevTools → Application → Cache Storage
2. Удалите все кэши
3. Обновите страницу
